07
Hook Storage & Beads Git Hooks Explained
Why .beads/hooks/ instead of .git/hooks/? Beads v1.0 sets core.hooksPath=.beads/hooks/ during bd hooks install. This redirects ALL git hooks to .beads/hooks/, which is git-tracked (travels with clones). Any custom git hooks (like our post-commit) MUST also live there.
Git Hooks
Stored in .beads/hooks/ (via core.hooksPath)
  • pre-commit — Beads: exports Dolt DB → issues.jsonl + stages .beads/ files. Ensures task data is committed alongside code.
  • post-merge — Beads: imports issues.jsonl → Dolt DB (3-way merge). Syncs task state after pulling/merging branches.
  • post-checkout — Beads: auto-imports if issues.jsonl changed on branch switch.
  • pre-push — Beads: validates JSONL consistency before push.
  • post-commit — Custom (GitNexus + Serena): reindexes graph + embeddings (background), signals LSP refresh. Beads does NOT use post-commit.
Claude Code Hooks
Stored in .claude/settings.json
  • SessionStart — Custom: runs .claude/helpers/session-start-hook.sh → bd prime + Serena reminder + GitNexus stale check
  • PreCompact — Beads: bd ready preserves task state through context compaction
  • PreToolUse — GitNexus: auto-enriches Grep/Glob/Bash with graph context (installed by gitnexus setup in ~/.claude/settings.json)
  • PostToolUse — GitNexus: warns if knowledge graph is stale after git mutations (installed by gitnexus setup in ~/.claude/settings.json)
  • PreToolUse — RTK: rewrites CLI commands for token optimization (in ~/.claude/settings.json)
Two settings.json files: Project-level (.claude/settings.json) has SessionStart + PreCompact. User-level (~/.claude/settings.json) has GitNexus PreToolUse/PostToolUse + RTK PreToolUse (global, shared across all projects). Both are merged at runtime.

Timing: analyze --embeddings does a full rebuild (~10-30s, entirely local, $0 cost). Runs in background — commits never blocked. Deleted files auto-dropped from index. Beads note: Beads v1.0 does NOT support post-commit hooks. Beads uses pre-commit (export Dolt→JSONL) and post-merge (import JSONL→Dolt) only.
