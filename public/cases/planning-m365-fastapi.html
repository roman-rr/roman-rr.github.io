Terraform Foundation

We deploy the full Azure skeleton: Resource Group, Key Vault, Entra ID, Container Registry, Log Analytics, and the Container Apps Environment. A single terraform apply and the cloud infrastructure is ready. You validate the foundation before any application development begins — no surprises down the road.

2 days$467
P1Phase 1 · Days 3–4

Messaging + FastAPI Shell

We provision Service Bus and Cosmos DB via Terraform, then deploy the FastAPI application with MSAL authentication and a Docker image on Container Apps. The Microsoft Graph webhook is configured and receives SharePoint notifications in real time. Messages flow into Service Bus.

2 days$467
P2Phase 2 · Days 5–7

Document Worker + AI Search

This is the core value. We build the document processing worker: fetch the file from SharePoint via Graph, extract text (PDF, DOCX, PPTX), chunk it, embed it via Azure OpenAI, and index it in AI Search. By the end of this phase, any document uploaded to SharePoint is searchable in under 60 seconds.

3 days$700
P3Phase 3 · Days 8–10

RAG Query API + Validation

We wire the RAG retrieval path: user question → hybrid search (vector + BM25) → context assembly → LLM answer with sourced citations. The API supports multi-turn conversations with context carry-over. 10 test queries validate retrieval accuracy, answer grounding, and citation correctness before the Copilot integration in P4.

3 days$700
P4Phase 4 · Days 11–12

Copilot Studio + Teams Bot

We connect the RAG pipeline to a real user surface. The Copilot Studio agent is grounded on AI Search, with FastAPI as an action plugin. Deployed to Teams so users can ask questions in their daily workspace. A web chat embed is available as fallback.

2 days$466
P5Phase 5 · Days 13–15

Hardening, Polish & Demo

We run the full stabilization sequence: error handling on all external calls, automatic Graph subscription renewal, edge case testing (large documents, duplicates). We prepare and rehearse the demo scenario. The knowledge base is pre-loaded with real content. Formal sign-off marks project close.

3 days$700
